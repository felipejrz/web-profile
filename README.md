# Felipe Juárez - Página Web de Perfil 🧑‍💻✨

Una página web personal creada con React, Vite y Material-UI, diseñada para mostrar información profesional, proyectos y habilidades de manera atractiva y moderna.

## Sitio Web 🌐

Puedes visitar la página web en [https://felipejuarez-profile.netlify.app](https://felipejuarez-profile.netlify.app) para explorar mi perfil.

## Características 🚀

- **Diseño Responsivo:** Compatible con dispositivos móviles y de escritorio gracias a Material-UI.
- **Sección de Proyectos:** Muestra una lista de proyectos destacados con descripciones y enlaces.
- **Información Personal:** Incluye una introducción, habilidades y contacto.
- **Animaciones Suaves:** Mejora la experiencia visual.

## Tecnologías 🛠️

- **React:** Biblioteca para construir interfaces de usuario.
- **Vite:** Herramienta de construcción rápida y moderna para proyectos web.
- **Material-UI:** Biblioteca de componentes para un diseño atractivo y funcional.
- **Netlify:** Servicio de hosting para el despliegue continuo.
- **JavaScript (ES6+):** Lenguaje principal para el desarrollo de la aplicación.

## Uso 🧭

- **Navegación Intuitiva:** Explora las diferentes secciones de la página como "Sobre mí", "Proyectos" y "Contacto".
- **Proyectos Interactivos:** Haz clic en los proyectos para ver más detalles y acceder a los enlaces relacionados.
- **Sección de Contacto:** Encuentra formas de contactarme fácilmente.
